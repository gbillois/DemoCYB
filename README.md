# DemoCYB

Un mini jeu **casse-brique cyberpunk** en HTML, CSS et JavaScript vanilla.

## Jouer

Ouvre `index.html` dans un navigateur moderne, puis clique sur **Lancer la partie**.

### Contrôles

- `←` / `→` ou `A` / `D` : déplacer la raquette
- Souris ou tactile : déplacer la raquette
- `Espace` : pause / reprise
